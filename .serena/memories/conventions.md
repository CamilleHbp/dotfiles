# Conventions

- Preserve chezmoi source-state prefixes and template suffixes; target visibility/path semantics are encoded in filenames.
- Keep platform-specific application snapshots under `darwin/<Application>/`; use symlink templates in the corresponding `private_Library/` or `private_dot_config/` path rather than duplicating live files.
- Gate platform-, architecture-, host-, personal-, headless-, and ephemeral-specific behavior with existing `.chezmoi` template data.
- Shell setup scripts use fail-fast behavior and shared task/error logging helpers; preserve the script's current shell dialect.
- Homebrew entries keep short descriptive comments and are grouped by package category as generated by the local Brewfile workflow.
- Treat staged application-state exports as intentional snapshots, but split commits by application or independent tooling concern when practical.
